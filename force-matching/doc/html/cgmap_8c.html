Detailed Description

Driver for the cgmap executable.

Authors
Will Noid, Wayne Mullinax, Joseph Rudzinski, Nicholas Dunn, Michael DeLyser

MRD 09/17/2018: I modified the user input to match the analysis programs I wrote. There's less command line options required now. We infer what trajectory file types are desired for both the input and output files based on the file extensions (and manually add a .trr extension if none of the standard extensions are found). Note, this new version can't do -b -e -dt like the old version. If you only want a subset of the trajectory mapped, then trim down the atomistic .trr file itself. Or, map the entire atomistic trajectory, and then trim the cg one.

Authors
Will Noid, Wayne Mullinax, Joseph Rudzinski, Nicholas Dunn, Michael DeLyser
