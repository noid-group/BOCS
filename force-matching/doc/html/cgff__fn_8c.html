◆ init_gmx_info()

void init_gmx_info ( tW_gmx_info * info)

init_gmx_info(): Initializes flags to conditions so that b_Forces_1 can be set to TRUE as soon as a frame is found with forces while b_Forces_N can be set to FALSE as soon as a frame is found that does not have forces.

This way we can determine wheter or not b must be calculated from dg/dr by checking ( b_Forces1 && b_Forces_N ).
