This folder contains example syntactic files for creating a CG force-field from multiple trajectories

when multiple molecule types are involved. (e.g. 19 single site Neopentane in 1890 single site methanol)

Please see the Extended Ensemble / Pressure Matching Tutorial provided in the User-Manual and in the tutorials folder for more complete examples. 

For simplicity this folder contains a version wherein the same .btp is linked several times with an extended ensemble of different biased trajectories. 

The Extended Ensemble / Pressure Matching tutorial contains examples for an extended ensemble over different system compositions
