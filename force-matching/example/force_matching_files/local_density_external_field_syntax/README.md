This folder contains file examples for force-matching a 1-site CG system (methanol). 

# cgff files 
- par.txt
- inp.txt (see ../branched_systems_with_LD_SG_interactions/)
- cg_methanol.btp

# ldcalc files
- LD_info.txt

with a pair-wise, LD, and external force requested in the parameterization from BOCS. 
Note that the External Field syntax employed is for a simulation box without pbc in the z direction. 
See the external field tutorial/BOCS user manual (cgff directives) for details.
